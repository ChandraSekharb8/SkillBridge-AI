About SkillBridge AI

SkillBridge AI is a career preparation platform built for students and freshers. It helps users improve resumes, prepare for interviews, understand job descriptions, and practice important placement questions using AI.

The main goal of this project is to bridge the gap between student skills and company expectations. Users can upload their resume, analyze it, match it with jobs, generate improved resume content, and prepare for interviews step by step.
